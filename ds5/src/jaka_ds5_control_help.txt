jaka-ds5-control - DualSense gamepad control for the JAKA arm

Reads a DualSense gamepad and streams commands to the jaka-cli serve
protocol over TCP. This binary is a pure protocol layer, it never links
the JAKA SDK.

Controls:
  Left stick     Move the head in the base XY plane
  Right stick    Rotate the head, up down tilts, left right turns
  L2 / R2        Move down / up
  Cross          Stop, abort the ongoing motion
  Circle         Reset to the default pose
  PS button      Power on
  Select         Power off

Usage:
  jaka-ds5-control [options]

Options:
  --ip <IP>       jaka-cli serve address, defaults to 127.0.0.1
  --port <port>   jaka-cli serve port, defaults to 5533
